Diagnosis

What this notice means

One common case of the problem is when a cell value contains more than 4096 characters.

Operational effect

Why it matters

The file could not be read as CSV at all, so nothing in it reaches validation. Everything that file defines is missing from the feed, and consumers will reject the dataset.

Scope

Affected files and report fields

The affected file is determined at validation time. Use the filename or related context field in your report to locate it.

Report fieldTypeMeaning
charIndexintegerThe location of the last character read from before the error occurred.
columnIndexintegerThe column index where the exception occurred.
filenamestringThe name of the faulty file.
lineIndexintegerThe line number where the exception occurred.
messageobjectThe detailed message describing the error, and the internal state of the parser/writer.
parsedContentobjectThe record number when the exception occurred.

Diagnosis

What usually causes it

  • A value such as Central Station, Platform 2 written without quotes, which splits one field into two.
  • An unbalanced double quote, after which the parser reads the rest of the file as one enormous value.
  • A stray line break inside a stop or route name.
  • A file saved as semicolon- or tab-separated by a spreadsheet using a European locale.
  • Mixed line endings, or a byte-order mark in the middle of the file rather than at its start.

Repair

How to fix it

Repair the file's CSV structure at source. Values containing a comma, a quote or a line break must be wrapped in double quotes, and a literal double quote inside a quoted value is written twice.

  1. 1
    Locate the record

    Open the file named in the report and use the report fields below to find the exact row.

  2. 2
    Change the source data

    Apply the repair described above to that record, and leave unrelated rows alone.

  3. 3
    Validate again

    Rebuild the GTFS archive and confirm that csv_parsing_failed no longer appears for the record.

Do not do this: Do not strip every comma out of your names to make the file parse. Quote the value instead — "Central Station, Platform 2" is legal CSV and keeps the name riders recognise.
